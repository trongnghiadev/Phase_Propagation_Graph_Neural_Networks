# pipelines/r/ – Thống kê bằng R

**Chức năng:** phân tích thống kê (đề cương Chương 4).

| File / thư mục (dự kiến) | Nội dung |
|---|---|
| `renv.lock` | khóa phiên bản gói R |
| `R/` | hàm dùng chung: kết nối `mongolite`, đọc Parquet, mẫu hình |
| `descriptive.R` | thống kê mô tả, xu hướng Mann–Kendall |
| `harmonic.R` | phân tích điều hòa thủy triều, B_harm, phần dư phi thiên văn |
| `phase_lag.R` | độ trễ pha triều và xả hồ (H5–H7) |
| `evaluation.R` | chỉ số và kiểm định dùng cho **mọi** mô hình |
