## 1. `graph_edges` (collection MongoDB)

Moi cạnh cua do thi hai chieu. Cung co cho ca hai chieu cua **cung mot cạnh** (mot ban ghi cho `dir: "down"`,
mot ban ghi cho `dir: "up"`), de moi nhanh deu biet ca hai chiều.

```json
{
  "src": 44042934,
  "dst": 44042930,
  "dir": "down",
  "virtual": false,
  "length_km": 3.214,
  "slope_used": 0.0001938,
  "celerity_ms": 1.83,
  "tau_phys_h": 1.756,
  "source_comid": 44042934
}
```

| Truong | Y nghia |
|---|---|
| `src`, `dst` | COMID cua nut nguon va nut dich (huong lan truyen) |
| `dir` | `"down"` (dong chay xuoi, theo `NextDownID`) hoac `"up"` (song trieu, nguoc `NextDownID`) |
| `virtual` | `true` cho canh ao: nut bien Vung Tau -> cua song; nut ho -> reach nga ha luu dap |
| `length_km` | do dai canh (km); canh ao lay theo do dai duong thoi gian cua nut ao |
| `slope_used` | do doc da sua dung de tinh `tau_phys_h` (khac `slope` goc khi canh sua `slope = 0`) |
| `celerity_ms` | van toc song (m/s) dung cho tinh `tau_phys_h` |
| `tau_phys_h` | do tre vat ly (gio) tren canh nay |

Nut ao (khong phai COMID that cua MERIT):

| Nut ao | COMID | Mo ta |
|---|---|---|
| bien Vung Tau | `SEA_VUNGTAU` | dai bien, dau nguon song trieu |

Canh ao: `SEA_VUNGTAU -> <COMID cua cua song>` voi `dir: "up"`, `virtual: true`.
Canh ao ho: `<COMID cua ho> -> <COMID nga ha luu dap>` voi `dir: "down"`, `virtual: true`.

## 3. `data/processed/features/g5/` (Parquet, phan vung theo nam)

Mot dong = mot (tram, ngay quan sat). Cac cot:

| Cot | Kieu | Y nghia |
|---|---|---|
| `station` | string | ma tram trong `stations` |
| `day` | string `YYYY-MM-DD` | ngay quan sat (gio Viet Nam) |
| `year` | int | de chia tap va phan vung |
| `h_peak1`, `h_peak2` | double | do cao dinh trieu thu nhat / thu hai (m), null = khong co so |
| `t_peak1_h`, `t_peak2_h` | double | gio trong ngay (0..24) cua dinh, null = khong co |
| `h_low1`, `h_low2` | double | do cao chan trieu thu nhat / thu hai (m) |
| `t_low1_h`, `t_low2_h` | double | gio trong ngay cua chan |
| `peak1_day_offset` | int | 0 = dinh thuoc ngay `day`, 1 = thuoc hom sau (qua nua dem) |
| `peak2_day_offset` | int | nhu tren |
| `missing_peak1`, `missing_peak2` | boolean | `true` = khong co dinh quan sat duoc (khong phai do gia tri 0) |
| `exceed_level` | string | muc bao dong cao nhat ma dinh dat: `""` / `"I"` / `"II"` / `"III"` |
| `res_inflow_m3s` | double | tong luu luong vao cac ho thuong nguon lien quan (m3/s) |
| `res_spill_m3s` | double | tong luu luong xa tran |
| `res_turbine_m3s` | double | tong luu luong qua may |
| `rain_mm` | double | tong luong mua tai cac tram mua thuoc luu vuc (mm/ngay) |
| `lunar_day` | int | ngay am lich (1..30) |
| `moon_phase` | double | pha mat trang (0..1, 0 = mat moi) |
| `astro_h1`, `astro_h2` | double | do cao trieu thien van du tinh tai Vung Tau cho dinh 1, dinh 2 cua ngay (m) |
| `astro_t1_h`, `astro_t2_h` | double | gio dinh trieu thien van du tinh (0..24) |

Quy tac:

- Chi lay nhanh co `qc = "ok"` (va `qc_flag != "suspect"` neu bo ca ngoai). Phan tu khong co so -> giu dong,
  cot gia tri null, cot `missing_* = true`.
- `astro_*` do `pipelines/r/harmonic.R` sinh ra (B_harm) va ghi lai vao cung mot file bang `data/processed/features/astro_tide.csv`
  (cot `day`, `h1`, `h2`, `t1_h`, `t2_h`); job G5 doc file nay de gan `astro_*`.
- Khong dung du lieu tu ngay `target_date` vao moi thuoc tinh dau vao cua mau do (kiem tra roi ri) (checklist GD3.6).
